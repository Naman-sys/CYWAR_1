framer-motion | Complex animations and page transitions

## Notes
- Dark mode is enforced as the default theme for the futuristic aesthetic.
- Authentication uses session-based cookies via /api/login, /api/register.
- API requests use credentials: "include" for auth persistence.
- Google Fonts (Orbitron, Inter) are loaded in index.css.
